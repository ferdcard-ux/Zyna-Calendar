# Términos y Condiciones - Zyna-Calendar

1. **Uso del Software**: Este widget es una herramienta de visualización de eventos. El usuario es responsable de la gestión de sus propias credenciales de Google.
2. **Privacidad**: La aplicación accede a Google Calendar de forma local. No se recolectan ni envían datos a servidores externos fuera de la infraestructura oficial de Google. Si activas el sistema de actualizaciones, la app consulta únicamente la API pública de GitHub para comprobar la versión de la release y descargar el paquete, sin transmitir datos personales.
3. **Sin Garantía**: El software se proporciona "tal cual", sin garantías de ningún tipo respecto a su funcionamiento en diferentes distribuciones de Linux.
